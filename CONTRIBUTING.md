# Contributing to PantryPal

Thanks for helping improve PantryPal.

1. Open an issue describing bugs or larger features before starting.
2. Keep the app usable offline except when a user explicitly imports a webpage.
3. Do not add trackers, ads, mandatory accounts, paywalls or paid APIs without prior discussion.
4. Never commit credentials, signing keys or private user data.
5. Build with JDK 17 and Gradle 8.13 (`gradle assembleDebug`) before submitting changes.
6. Ensure new dependencies have licences compatible with this project.

Contributions are submitted under the project's MIT licence.
